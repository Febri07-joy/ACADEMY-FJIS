Rasionalisasi SNBT

Versi ini memisahkan kemampuan UTBK, tekanan kompetisi prodi, konteks universitas, dan kualitas data. Analisis memisahkan profil UTBK, bidang studi, PTN, fakultas/prodi, jenjang, indikator kompetisi, dan kualitas data. Hasil adalah estimasi model internal FJIS. Sistem memisahkan indeks kecocokan dari estimasi peluang berbasis data historis. Tidak ada angka yang dianggap sebagai passing grade resmi.

1. Skor UTBK per Subtes

Isi 7 skor UTBK. Sistem membaca kekuatan dan kelemahan subtes, bukan sekadar rata-rata.

PM
Pembobotan subtes di bawah adalah model internal FJIS. SNPMB menyatakan SNBT 2026 berbasis hasil UTBK, dan portofolio ditambahkan untuk prodi seni/olahraga. cite tidak ditulis di HTML: sumber resmi ada di halaman SNPMB.

2. Bidang Program Studi

Pilih bidang untuk melihat bobot internal FJIS.

3. Pilihan PTN → Program Studi

Pilih PTN terlebih dahulu. Program studi kemudian difilter berdasarkan katalog lokal. Untuk PTN yang belum memiliki daftar prodi di katalog ini, sistem tidak akan mengarang jurusan: pilihan akan ditandai sebagai data prodi belum dimuat.

4. Hasil Analisis FJIS

Setiap pilihan dianalisis sendiri. Indeks FJIS adalah skor kecocokan 0–100, sedangkan estimasi peluang model dihitung terpisah dari rasio diterima/peminat atau daya tampung/peminat. Angka tersebut bukan peluang resmi SNPMB/PTN.

Rata-rata 7 subtes—
Skor berbobot bidang—
Subtes terkuat—
Subtes terlemah—
Penting: FJIS tidak boleh menyimpulkan “pasti lolos” atau “pasti gagal”. Tingkat persaingan masuk berubah setiap tahun dan syarat penerimaan ditentukan PTN/prodi. Jika data daya tampung, historis, atau akreditasi belum tersedia, sistem harus menyatakan data tersebut belum tersedia—bukan membuat angka.

Metode Keketatan & Pengaman Hasil

FJIS menggunakan dua jenis data: data resmi pendaftar+diterima bila tersedia, atau daya tampung SNBT + peminat terbaru sebagai indikator tekanan kursi bila angka diterima per prodi tidak tersedia. Sistem tidak mengubah data daya tampung menjadi "angka diterima". Jika data kompetisi prodi belum tersedia, sistem tidak membuat persentase peluang. Indeks juga dibatasi agar profil biasa tidak terlihat terlalu optimistis. Untuk prodi dengan data resmi, rasio penerimaan historis menjadi jangkar; untuk prodi tanpa angka diterima, sistem memakai daya tampung sebagai dan menandainya secara eksplisit. Akreditasi juga tidak ditebak: prodi hanya mendapat penyesuaian akreditasi setelah statusnya diverifikasi dari lembaga akreditasi yang relevan.

Dasar data dan status katalog

Daftar PTN pada versi ini mengikuti daftar pusat UTBK resmi SNPMB 2026. Halaman daya tampung resmi SNPMB menyebut data daya tampung program studi SNBT 2026 tersedia untuk 146 PTN dan menampilkan data historis lima tahun. Versi ini sudah menyiapkan struktur database untuk menampung data tersebut, tetapi belum mengklaim katalog prodi nasional lengkap sebelum data prodi resmi dimasukkan. Akreditasi prodi juga harus diisi dari sumber akreditasi resmi (BAN-PT/LAM), bukan ditebak dari reputasi kampus.
